# Get $MON


Tadle's Token Station offers two ways to **Top up $MON**  :

- **Ethereum via CCIP**
- **Base Network via Bridge Router**

Select Ethereum or Base to complete your exchange quickly and securely.

---


### Quick Guide

1. Switch to **Ethereum** or **Base** — the Token Station will open automatically.  
2. Choose the token to swap: **ETH, USDT, or USDC**.  
3. Swap into **MON** or **monUSD** on the Monad network.  
4. (Optional) Enter another wallet address to receive the tokens.  




> **Note:**  
> - Make sure your wallet is connected before starting a swap.  
> - Ensure you have enough native tokens (**ETH** or **Base ETH**) to cover gas fees.
